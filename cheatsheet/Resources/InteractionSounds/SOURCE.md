# 交互短音来源

cabinet-copy.wav 和 cabinet-save.wav 为本项目自行程序合成的原创声音，生成器为 scripts/generate_cabinet_sounds.py。仅使用正弦波、确定种子的噪声与包络，不含外部采样、录音、下载素材或第三方音效。可随本项目使用、修改和分发，无第三方素材署名或许可要求。

复制音 105ms，保存音 75ms，48kHz / PCM16 / 单声道。共同采用柔和起音、短促低中频振动和快速衰减；保存音的幅度更低、尾音更短。独立音效音量默认设为 35%，与系统当前音量共同决定播放响度，不修改系统音量。源文件保留余量和尾部淡出，不使用循环播放。
