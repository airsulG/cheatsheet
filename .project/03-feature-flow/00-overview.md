# Feature Flow Overview

| Flow | File | Status | User Stage |
|---|---|---|---|
| Shelf command import | `01-shelf-command-import.md` | ready_for_execution | Add many command snippets into a selected Shelf category |
| Shelf live command refresh | `02-shelf-live-command-refresh.md` | ready_for_execution | See saved command changes immediately in the current Shelf list |
| App settings route | `03-app-settings-route.md` | ready_for_execution | Manage backup, restore, clipboard retention, and cleanup from one Settings window |

Current design boundary: this folder describes Shelf-adjacent command management and global settings entry behavior. It does not redefine backup archive format, clipboard capture parsing, or prompt package taxonomy.
